# AI聊不停 · 备份与恢复（C2，2026-11-13）

**备份脚本**：`备份.py`（`备份.bat` 为双击入口）
**备份位置**：`~/备份/每日/YYYY-MM-DD/`（`--root` 可改）
**计划任务**：`AI聊不停-每日备份`，每天 03:00（当前用户，避免锁屏/休眠时跳过可设为「唤醒计算机运行」）
**保留**：最近 7 天（`--keep N` 可改）；日志 `<root>/备份.log`（>5MB 自动轮转）

## 一、每天备份什么

| 条目 | 源 | 说明 |
|---|---|---|
| `台账.sqlite3` | `桌面端\数据\台账.sqlite3` | sqlite backup API 一致性快照（服务运行中也安全），备份后做 `PRAGMA integrity_check` 与关键表行数核对 |
| `memsearch\` | `~/.memsearch/` | MemSearch 配置 + Milvus Lite 库 |
| `共享记忆库/` | `$AI_CHAT_SHARED_DIR`（默认 `~/共享记忆库`） | 可选，共享规则/技能目录 |
| `DS记忆库/` | `$AI_CHAT_DS_DIR`（默认 `~/DS记忆库`） | 可选，工作台账目录 |
| `manifest.json` | 同上目录 | 每个条目的文件数、字节、关键文件 sha256、成败 |

## 二、恢复演练（建议每月 1 次，5 分钟）

> 演练前：把要恢复的条目先复制一份旧文件留底；演练只对**临时副本**动手，不碰真实库。

1. **台账恢复**
   1) 退出「AI聊不停」（窗口 + `服务.py` + `派发器.py`，确保 `数据\台账.sqlite3` 无进程占用）；
   2) 把 `备份\每日\<日期>\台账.sqlite3` 复制回 `数据\台账.sqlite3`；
   3) `python -c "import sqlite3;c=sqlite3.connect(r'数据\台账.sqlite3');print(c.execute('PRAGMA integrity_check').fetchone())"` → 应为 `ok`；
   4) 核对行数：`projects / tickets / group_messages / signoffs` 与备份时 manifest 的数字一致；
   5) 启动窗口，抽查 3 个工单详情能否打开、群聊能发一条测试消息。
2. **MemSearch 恢复**：把 `<日期>\memsearch\` 复制回 `~/.memsearch/`（先改名旧目录）；`memsearch config list --resolved` 与 `memsearch search "测试"` 能出结果即通过。
3. **记忆空间恢复**：把 `<日期>\共享记忆库\`、`DS记忆库\` 覆盖回原盘（建议先 `git`/手动备份旧目录）；重点核对 `00_总索引.md` 与 `00_状态.md` 是否能打开、编号连续。
4. **记录**：在《03_经验与工具》或本文件末尾追加一行「演练日期 / 恢复条目 / 结果 / 耗时」。

## 三、已知边界

- Milvus Lite 是单进程独占库：备份复制的 `memsearch\` 目录在**服务运行中**可能处于 WAL 状态；恢复后首次启动会自动 checkpoint，不影响使用。
- `~/.memsearch/` 不含 ONNX 模型缓存（`~/.cache/huggingface/`），模型需另行保留或可重新下载。
- 备份不做全盘镜像，只覆盖上述四类；新增重要数据源时请在 `备份.py` 里加条目。
