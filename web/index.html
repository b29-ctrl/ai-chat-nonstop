AI岗位怎么配

这是「通用版」：AI 岗位只是配置项，不写死产品名。后续把 派发器.py 接进同一张 SQLite 台账，这里就会实时显示真实流转。

AI 名称可**双击**直接改（写回 配置.json 的 label）。

  • WorkBuddy：process 型，CodeBuddy CLI；API Key 放本机 secrets 文件。
  • COZE：http 型，云端评审；Token 只存本机。
  • DSH / CODEX：process 型，按本机 CLI 路径接入。

新增 AI 的流程

点上方「+ 新增 AI」→ 填名称 / 类型 / 默认岗位 / 命令 → 保存（写前自动备份 配置.json.bak.<时间戳>）→ 卡片立即出现，无需重启。新 AI 不自动加入任何项目：去「项目管理 → AI 成员」勾选后，默认岗位作为初始值自动落位，可在「岗位编制」覆盖。Key/Token 只填本机密钥文件路径，禁止粘贴明文；导出文件不含 Key、命令、本机路径。

技能怎么装（通用规则）

技能装到执行端，不装进调度台。判定顺序：技能发现路径 → 是否可见 → none / prompt / path / api / impossible → 实测「使用技能 X」。完整规则见随包分发的 技能桥接规则.md。

归档项目
